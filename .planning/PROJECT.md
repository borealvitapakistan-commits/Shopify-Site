# Boreal Vita Storefront Redesign

## Vision

Refactor the existing Shopify Liquid theme into a calm, premium Boreal Vita storefront: northern apothecary meets modern science.

## Current Constraint

Halal certification should not lead the browser title, homepage, or main navigation. It belongs in the About Us/trust standards context, where customers can verify it without the brand shouting it.

## Platform

Shopify Liquid theme refactor in place. No headless migration unless the owner explicitly changes direction.

## Creative Flavor

Luxe-Natural / Editorial: deep teal equity, generous spacing, clear labels, warm gold used as light and proof rather than small text.

## One Unforgettable Thing

The storefront should feel like holding the bottle and seeing the label come alive online: the same teal, gold, proof, and calm clarity translated into accessible web components.
